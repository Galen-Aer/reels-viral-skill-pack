Это готовые системные промпты для Claude и ChatGPT, которые генерируют вирусные сценарии для Instagram Reels и TikTok в нише: нейросети и ИИ для новичков.

## Как использовать

### Вариант 1: Claude

1. Открой Claude (claude.ai)
2. Нажми на профиль → "Custom instructions"
3. В поле "System prompt" вставь весь текст из **claude-reels-skill-ru.md**
4. Сохрани

Теперь отправляй Claude команду вида:

```
Создай вирусный 20-секундный сценарий Reels про самые частые ошибки новичков с ChatGPT.

Тема: "Ошибки новичков с ChatGPT"
Аудитория: люди 18-35, без опыта в ИИ
Длительность: 20 секунд
Тон: энергичный, практичный, ясный
Цель: просмотры и сохранения
```

### Вариант 2: ChatGPT

1. Открой ChatGPT (openai.com)
2. Нажми на профиль → "Settings" → "Custom instructions"
3. Включи переключатель "Custom instructions"
4. В поле "How would you like ChatGPT to behave?" вставь весь текст из **chatgpt-reels-skill-ru.md**
5. Сохрани

Теперь отправляй ChatGPT команду вида:

```
Создай вирусный сценарий TikTok (30 сек) про миф и реальность работы с нейросетями для новичков.

Тема: "Миф vs реальность: что реально нужно знать о нейросетях"
Аудитория: новички в ИИ, 18-40 лет
Длительность: 30 секунд
Тон: динамичный, ясный, без занудства
Цель: удержание внимания и шеры
```

## Что работает лучше всего

✨ **Сильные углы в этой нише:**
- Ошибки новичков
- Миф vs реальность
- Before/after трансформации
- Простые лайфхаки
- "Почему все делают неправильно"
- "Что упускают 90% новичков"
- Демонстрация инструмента (живой пример)
- Быстрые решения задач с ИИ

💡 **Лучшие длительности:**
- 15 сек (для Reels, когда тема простая)
- 20 сек (универсальная длина)
- 30 сек (для подробного объяснения)
- 45 сек (для историй и демонстраций)

## Советы для лучших результатов

1. **Будь конкретен в теме** — вместо "расскажи про ИИ" лучше "расскажи про 3 ошибки новичков с Midjourney"
2. **Укажи реальную аудиторию** — система лучше работает, когда знает, кому это нужно
3. **Выбери правильный тон** — "энергичный" vs "экспертный" vs "дружелюбный" = разные скрипты
4. **Скажи реальную цель** — "просмотры", "сохранения", "клики", "подписка" = разный CTA
